- 术语翻译一致性

## 5. Key Data Points (SERP Verified)

| Data Point | Source |
|-----------|--------|
| UN38.3 = 8 destructive tests (T.1–T.8) | UN Manual of Tests and Criteria §38.3 |
| 危包证 validity: sea/road 12 months, air 3 months | China Customs |
| SoC ≤30% mandatory for air freight (IATA DGR 67th, Jan 2026) | IATA |
| 3-meter stacking test now mandatory in UN38.3 (2026) | UN Rev.7 |
| IMDG Code 42-24: new UN3556/3557/3558 for NEVs | IMO |
| UN38.3 test summary must be signed + match MAWB | IATA |
