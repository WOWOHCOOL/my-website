## 4. Key Data Points（2026 新规 · 均来自俄语本土调研）

### 4.1 2026 收紧（Постановление Правительства РФ № 1669, с 01.01.2026）

| 项 | 规则 |
|---|---|
| 发证机构 | 仅 Росаккредитация 授权机构，证书号 RA.RU 开头；其他 EAEU 国证书在俄失效 |
| 实验室 | 仅俄本土 RA/RU 实验室；CE/CB/CNAS 报告仅作参考，不能直接转换 |
| 证书形式 | 纸面证书废止，唯一有效 = ФГИС 电子证书（5 天录入） |
| 持证人 | 仅俄法人（ООО/ИП），外资需委任 уполномоченный представитель（公证协议） |
| 标记 | 动态加密 QR 码（季度换密钥）+ знак EAC ≥5×5mm + 俄语铭牌 |
| 电商 | 2026-07-01 起 Ozon/Wildberries 商品页须显示动态 QR 码 |
| 过渡 | 2025-07 前旧证须在 2026-06-30 前补 QR + 俄持证人，否则失效 |
| 罚则 | 扣货/退回 + 罚款 20-50%（最高 200%）+ 海关黑名单 + 平台下架冻结 |

### 4.2 移动电源适用法规

| 法规 | 内容 |
|---|---|
| ТР ТС 004/2011 | 低压设备安全（绝缘/耐压/防触电/过热/防火） |
| ТР ТС 020/2011 | 电磁兼容（EMC：辐射/传导/静电/抗扰） |
| ТР ЕАЭС 037/2016 | RoHS（铅/汞/镉等 6 有害物质） |
| UN 38.3 | 锂电池运输测试（海关强制） |
| IEC 62133 / ГОСТ | 电芯安全（过充/过放/短路/挤压/热冲击） |
| ТН ВЭД | 850760（锂离子电池）/ 850440（充电设备） |

> ⚠️ **数据准确度警告**：部分来源引用「ТР ТС 038/2016 锂电池安全法规」，**该法规号不存在**（RoHS 是 037/2016）。锂电芯安全走 UN38.3 + IEC 62133，勿在正文引用不存在的法规号。DoC vs CoC 的分类在各来源互相矛盾（部分称 2026 起强制 CoC，部分称按容量/功能风险分级）——正文应如实呈现「分界不清是真实陷阱」，并建议以 Росаккредитация 具体型号为准，不替读者下绝对结论。
