## 4. Recommended Outline 增量（不重写，只补）

保留现有 6 大 H2 + Conclusion 结构。新增/强化点：

### Section 1 增强：PD 协议握手
当前段落只讲 PPS 优势。新增 200 词块：

```
H4 (新): The PD Handshake — How Charger and Device Negotiate Power

Step 1: Source advertises capabilities (e.g., 5V/3A, 9V/3A, 15V/3A, 20V/5A)
Step 2: Sink requests one profile based on device need
Step 3: Source accepts and switches voltage within ~50ms
Step 4: Continuous monitoring; renegotiation if load changes

Why this matters: A "PD-rated" charger that fakes the handshake will fall back to 5V/3A (15W) silently.
USB-IF certified products pass interoperability testing on this exact sequence.
```
